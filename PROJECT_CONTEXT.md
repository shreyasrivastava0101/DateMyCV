# DateMyCV

Tagline: Your CV deserves better.

## Project Idea

DateMyCV is a swipe-based job and internship discovery platform.

Users can:

- Swipe left to reject a job
- Swipe right to apply or start an application
- Swipe up to save a job
- View job details
- Upload and manage resumes
- Track applications
- Get job-match scores based on their profile and skills

## Development Rules

- Use ES Modules with import/export
- Keep frontend and backend separate
- Use REST APIs
- Keep secrets inside .env
- Do not hardcode passwords or API keys
- Build one feature at a time
- Do not modify unrelated files
- Explain important architectural changes before making them
